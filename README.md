# Rose-Lavender-Pestilence
"Rose, Lavender, Pestilence" is a nickname given to my personal hobby Godot project aimed at building a mobile game akin to the one presented in fraudulent ads of Last Asylum: Plague. The full story is that my girlfriend saw one of those ads and really liked what she saw, so she installed the game and of course she was upset that it's not like the ads. She complained about it to me, and luckily, I'm an aspiring game developer, so I took on the task of building the game for her, as well as my personal portfolio.
## Demo build 1.0.0
This version of the game is simply a demo of an animated 3D character walking around with a 2-layer controls scheme (keyboad + on-screen joystick).
It's also my first ever 3D game in Godot.
